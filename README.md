# Ketham Harika - Personal Portfolio

A responsive and accessible Personal Portfolio Web Application created for Full Stack Development Assignment-1.

## Technologies
- HTML5 semantic structure
- CSS3
- Bootstrap 5
- JavaScript ES6+
- Bootstrap Icons

## Assignment Coverage

### HTML5
- Semantic header, nav, main, section, article, aside and footer
- Headings, lists, links and images
- Education table
- Contact form
- Accessibility attributes

### CSS3 & Responsive Design
- CSS selectors
- Box model
- Typography and gradients
- Positioning
- Flexbox
- CSS Grid
- Animations and transitions
- **Mobile-first base styles**
- Progressive media queries at 576px, 768px, 992px and 1200px
- Reduced-motion accessibility support

### Bootstrap
- Responsive navbar
- Grid system
- Cards
- Buttons
- Forms
- Responsive table
- Alerts

### JavaScript ES6+
- const/let variables
- Functions and arrow functions
- Arrays and objects
- Conditions and loops
- DOM manipulation
- Event listeners
- Theme switching with localStorage
- Typing animation
- Skill filtering
- Project filtering
- Scroll progress
- Active navigation
- IntersectionObserver reveal animations
- Client-side form validation
- Dynamic success/error messages

## Run
1. Extract the project folder.
2. Open `index.html` in a browser, or use VS Code + Live Server.
3. Internet access is required for Bootstrap CDN assets.

## Submission
Submit the complete project folder/repository rather than only `index.html`, because CSS, JavaScript and assets are part of the working application.


## Requirement Verification

- HTML5 semantic sections: Home, About, Education, Skills, Projects, Experience, Achievements/Certifications, Contact
- HTML elements: headings, lists, links, image/graphic, table and contact form
- CSS3: selectors, box model, typography, colours, positioning, Flexbox, Grid, animations and transitions
- Mobile-first responsive CSS with progressive media queries
- Bootstrap: navbar, grid, cards, buttons, forms, responsive table and alerts
- JavaScript ES6+: let/const, functions, arrow functions, arrays, conditions, loops and DOM manipulation
- Interactive features: theme switching, typing animation, skill filtering, project filtering, scroll progress and active navigation
- Validation: client-side contact-form validation with dynamic error/success messages
- Accessibility: skip link, semantic structure, labels, ARIA live feedback, keyboard focus and reduced-motion support
